Every redesigned route's layout inherits this one. data-view is the page's own front-matter `view` (home · work · blog · post · cv · talks). It marks the current link in the navbar, widens the post's gutter at ≥960px, and tells assets/js/redesign.js which section list to spy on. A page that sets nothing marks nothing, which is correct for the legacy routes that borrow this shell. data-theme is stamped by the blocking boot script at the top of , then owned by assets/js/_main.js, which toggles it from the control in the navbar — exactly the mechanism :root[data-theme="dark"] in the redesign stylesheet is written against. The boot script exists because _main.js is a deferred module and cannot run before the first paint; see the comment there. No `layout: compress`: the sprite's paths and the posts' 
  listings are both whitespace-significant, and the compressor is not worth
  the risk for what it saves.
